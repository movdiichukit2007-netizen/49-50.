Про веб-додаток PostService

Назва проєкту: Веб-додаток «Облік поштових відправлень»

Призначення: Автоматизація обліку, створення, редагування та моніторингу поштових посилок і відправлень.

Версія: 1.0 (Клієнтський модуль на базі Fetch API)

Технологічний стек

  • HTML5 — розмітка структури сторінок та форм;
  • CSS3 — адаптивна стилізація інтерфейсу відповідно до макетів ПР-44;
  • JavaScript (ES6+) — логіка SPA-навігації, валідація, взаємодія з DOM;
  • Fetch API — асинхронні HTTP-запити (GET, POST, PUT, DELETE);
  • REST API PostService — серверна база обробки даних.

Правила валідації даних

  • Поля «Відправник» та «Одержувач» є обов'язковими для заповнення (мінімум 2 символи);
  • Опис вмісту обов'язковий (мінімум 2 символи);
  • Вага та всі геометричні габарити (довжина, ширина, висота) мають бути строго більшими за 0;
  • Оголошена цінність та вартість доставки не можуть бути від'ємними.
